# servidor-de-arquivos

Compartilha uma pasta na rede local e mostra o endereço certo

Código do carrossel publicado no [@python_brasil](https://instagram.com/python_brasil).

## Como rodar

```bash
python main.py --help
```

```bash
python main.py --pasta ~/Downloads --porta 8000
```

## O que este código NÃO faz

- **serve a pasta sem autenticação** para quem está na mesma rede
- não use em rede pública, e desligue ao terminar
